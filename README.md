# Mad Libs Story Game

## Description
An interactive Python game that creates funny stories using words entered by the user.

## Features
- Three story templates: Hospital, Camping, and Enchanted Castle.
- Random template selection.
- Repeats the question when the user enters an invalid choice.
- Uses variables, conditions, functions, loops, lists, strings, and the random library.

## How to Run
Run the following command:

python main.py
